# ระบบแนวข้อสอบ วิชา 202 ช่างกลโรงงานและเทคนิคการผลิต

เว็บฝึกทำข้อสอบแบบไฟล์เดียว (`index.html`) ไม่ต้องมีเซิร์ฟเวอร์

- คลังข้อสอบ 21 ชุด รวม 1,115 ข้อ พร้อมเฉลย
- แดชบอร์ดคะแนน สอบจำลองแบบสุ่มพร้อมจับเวลา
- จัดการผู้ใช้งานและรหัสผ่าน คลัง PDF นำเข้า/ส่งออก JSON
- เก็บข้อมูลในเบราว์เซอร์ของแต่ละเครื่อง (localStorage / IndexedDB)

## เปิดใช้งานบน GitHub Pages
1. Settings → Pages → Source เลือก **GitHub Actions**
2. Push ขึ้นสาขา `main` ระบบจะ deploy เอง
3. ลิงก์: `https://<username>.github.io/<repo>/`

## ข้อควรระวัง
- รหัสผ่านผู้ดูแลเริ่มต้นคือ `1234` อยู่ในโค้ดซึ่งเปิดดูได้ ใช้เพื่อแยกสถิติเท่านั้น ไม่ใช่ความปลอดภัยจริง
- ตัวอ่านและตัวแปลง PDF ต้องใช้อินเทอร์เน็ต (โหลดไลบรารีจาก CDN)
