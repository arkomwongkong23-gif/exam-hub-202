# เตรียมสอบครูผู้ช่วยอาชีวะ วิชาเอก 202 : ช่างกลโรงงานและเทคนิคการผลิต

เว็บต้นแบบภาษาไทยสำหรับฝึกทำและจัดการข้อสอบวิชาช่างกลโรงงานและเทคนิคการผลิต ใช้ HTML, CSS และ JavaScript เปิดใช้งานได้โดยไม่ต้องติดตั้งแพ็กเกจ

## เริ่มใช้งาน

1. เปิด `index.html` ในเบราว์เซอร์
2. รหัสผ่านเริ่มต้นคือ `1234` แล้วเปลี่ยนได้จากเมนู **ตั้งค่ารหัสผ่าน**
3. ตั้งชื่อผู้ดูแลระบบและเปลี่ยนรหัสผ่านได้ในเมนู **ตั้งค่ารหัสผ่าน** ชื่อที่กำหนดจะแสดงบริเวณมุมขวาบน
4. สร้างชุดข้อสอบ จากนั้นกด **เพิ่มคำถาม** เพื่อใส่โจทย์ ตัวเลือก เฉลย และคำอธิบาย
5. ทำข้อสอบจากหน้า **คลังข้อสอบ**

มีตัวอย่างชุด “พื้นฐานงานกลึง” ให้ลองใช้งาน สามารถลบหรือแก้ไขข้อมูลโดยเพิ่มคำถามหรือสร้างชุดใหม่ได้

## สำรองและนำเข้าข้อสอบ

เมนู **จัดการข้อสอบ** ส่งออกได้ทั้งรายชุดและทั้งคลังเป็น JSON และนำเข้า JSON ที่ส่งออกจากระบบนี้ได้ ข้อมูลจะถูกรวมเข้าคลังปัจจุบัน

ตัวอย่างรูปแบบไฟล์:

```json
{
  "version": 1,
  "sets": [
    {
      "title": "พื้นฐานงานกลึง",
      "description": "ความรู้เบื้องต้น",
      "questions": [
        {
          "text": "อุปกรณ์ใดใช้จับชิ้นงานทรงกระบอก?",
          "options": ["หัวจับสามจับ", "ค้อน", "ประแจ", "เหล็กขีด"],
          "answer": 0,
          "explanation": "หัวจับสามจับเหมาะกับชิ้นงานทรงกระบอก"
        }
      ]
    }
  ]
}
```

`answer` เริ่มนับจาก 0 (0 คือ ตัวเลือกแรก)

## ข้อจำกัดของรุ่นนี้

รุ่นนี้เก็บข้อสอบและรหัสผ่านไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้น รหัสผ่านเป็นเพียงประตูเข้าใช้งานหน้าเว็บ ไม่ใช่ระบบยืนยันตัวตนฝั่งเซิร์ฟเวอร์ จึงเหมาะกับการทดลองใช้หรือใช้งานส่วนตัวบนเครื่องเดียว ยังไม่เหมาะสำหรับเผยแพร่เป็นระบบออนไลน์หลายผู้ใช้หรือใช้คุมสอบจริง ข้อมูลไม่ซิงก์ข้ามเครื่อง และควรสำรองไฟล์ JSON เป็นระยะ

ไฟล์ PDF ยังแนบหรือแปลงเป็นข้อสอบอัตโนมัติไม่ได้ในรุ่นนี้ ต้องป้อนข้อสอบจาก PDF เองหรือนำเข้าผ่าน JSON หากต้องการให้ผู้เรียนหลายคนเข้าใช้ระบบเดียวกันอย่างปลอดภัย ควรต่อยอดเป็นแอปที่มีฐานข้อมูลและตรวจสอบรหัสผ่านที่เซิร์ฟเวอร์

เมนูนำเข้ารองรับ PDF ที่มีข้อความเลือกได้ โดยแยกข้อสอบปรนัยที่มีตัวเลือก 4 ข้อ (ก. ข. ค. ง.) และเฉลยตามรูปแบบเลขข้อ ผู้ใช้ตรวจแก้ตัวอย่างก่อนดาวน์โหลด JSON หรือนำเข้าคลังได้ PDF สแกนภาพยังต้อง OCR ก่อน ระบบโหลด PDF.js จาก CDN จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อใช้ตัวแปลงนี้

ชุด JSON ที่แปลงจาก PDF หนังสือซึ่งมีภาพประกอบสามารถบรรจุภาพตัดของข้อสอบไว้ในฟิลด์ `sourceImage` เพื่อให้แสดงภาพระหว่างทำข้อสอบได้
