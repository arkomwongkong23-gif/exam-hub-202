# ระบบแนวข้อสอบ วิชา 202 ช่างกลโรงงานและเทคนิคการผลิต

เว็บฝึกทำข้อสอบแบบไฟล์เดียว (`index.html`) ไม่ต้องมีเซิร์ฟเวอร์

- คลังข้อสอบ 21 ชุด รวม 1,115 ข้อ พร้อมเฉลยและภาพประกอบ
- แดชบอร์ดคะแนน สอบจำลองแบบสุ่มพร้อมจับเวลา
- ผู้ดูแลจัดการผู้ใช้งานและรหัสผ่านได้ ผู้ใช้ทั่วไปไม่เห็นเมนูจัดการ
- คลัง PDF: เอกสารส่วนกลาง (โฟลเดอร์ `pdfs/`) และเอกสารส่วนตัวในเบราว์เซอร์
- ใช้ได้ทั้งมือถือ iPad และคอมพิวเตอร์

## เปิดเป็นเว็บ (GitHub Pages)
Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save

## เพิ่มเอกสารในคลัง PDF ส่วนกลาง
อัปโหลดไฟล์ `.pdf` ลงโฟลเดอร์ `pdfs/` ในรีโป ไฟล์จะแสดงให้ทุกคนอัตโนมัติ

## ข้อควรระวัง
- รหัสผ่านผู้ดูแลเริ่มต้นคือ `1234` อยู่ในโค้ดซึ่งเปิดดูได้ ใช้แยกสถิติเท่านั้น ไม่ใช่ความปลอดภัยจริง
- ผลสอบและรายชื่อผู้ใช้เก็บในเบราว์เซอร์ของแต่ละเครื่อง
- ตัวอ่าน PDF และฟอนต์โหลดจากอินเทอร์เน็ต

## แก้ไขข้อสอบ (เฉพาะผู้ดูแลระบบ)
1. ล็อกอินด้วยรหัสผ่านผู้ดูแล → เมนู **จัดการข้อสอบ** → กด **✎ แก้ไขคำถาม** ที่ชุดข้อสอบ (หรือกด **✎ แก้ข้อนี้** ระหว่างทำข้อสอบ)
2. แก้โจทย์ ตัวเลือก และเลือกวงกลมเฉลยที่ถูกต้อง แล้วกด **บันทึกข้อนี้** (ถ้าแก้เฉลย คะแนนย้อนหลังจะถูกคำนวณใหม่)
3. ผลที่แก้เก็บในเบราว์เซอร์ของผู้ดูแลก่อน หากต้องการให้ทุกคนเห็น ให้กด **ส่งออก questions.json** ในหน้าจัดการข้อสอบ
   แล้วอัปโหลดไฟล์ `questions.json` ทับของเดิมใน GitHub (Add file → Upload files) รอ 1–2 นาที ทุกคนจะได้ข้อสอบฉบับแก้ไข
