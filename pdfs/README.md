# โฟลเดอร์คลัง PDF ส่วนกลาง

อัปโหลดไฟล์ PDF ลงในโฟลเดอร์นี้ (Add file → Upload files) แล้วรอ 1–2 นาที
ไฟล์จะปรากฏในเมนู **คลัง PDF → เอกสารส่วนกลาง** ให้ทุกคนเปิดอ่านได้

- ไฟล์ละไม่เกิน 25 MB (ข้อจำกัดของการอัปโหลดผ่านเว็บ GitHub)
- ตั้งชื่อไฟล์ให้สื่อความหมาย เช่น `สรุปงานกลึง.pdf`
- ลบไฟล์โดยเปิดไฟล์ใน GitHub แล้วกดไอคอนถังขยะ
